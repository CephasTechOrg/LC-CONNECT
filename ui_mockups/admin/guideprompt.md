# LC Connect Campus Admin Dashboard — UI Refinement Prompt

## Objective

I am providing an inspiration image of our CURRENT LC Connect Admin Portal.

Your task is NOT to redesign it from scratch.

Instead, evolve it into a production-ready enterprise admin dashboard while preserving the existing architecture, navigation, and workflow.

This is an enhancement project.

Keep the current layout philosophy, but dramatically improve the visual quality, spacing, typography, consistency, and scalability.

Think like a senior product designer modernizing an existing SaaS platform rather than creating a brand-new product.

Generate ONLY ONE desktop dashboard page.

---

# Platform Context

LC Connect is the official campus platform for Livingstone College.

The Admin Portal is used by campus administrators to manage the entire platform.

The backend already exists.

The navigation already exists.

The Honors Program is simply another module inside the existing Admin Portal.

It is NOT a separate application.

Everything should feel unified.

---

# Design Philosophy

The current dashboard feels too busy.

The redesign should prioritize:

• simplicity
• whitespace
• hierarchy
• focus
• clarity

The dashboard should answer one question immediately:

"What are the most important things requiring my attention today?"

Avoid trying to display every piece of information.

Show only what administrators need immediately after logging in.
