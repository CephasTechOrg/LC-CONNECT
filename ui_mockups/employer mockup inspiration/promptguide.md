# Employer Partner Portal — Blueprint Bond (LC Connect)

## Objective

Design ONE single high-fidelity desktop web application dashboard for the Employer Partner Portal of LC Connect's Blueprint Bond platform.

This is NOT a generic recruiting platform.

Blueprint Bond is a verified Presidential Scholars program inside Livingstone College's official LC Connect ecosystem.

Only employer partners that have been reviewed and approved by the Honors Program administrators can access this dashboard.

The goal of this interface is to help approved employers recruit Presidential Scholars in a professional, enterprise-grade environment.

The interface should feel like software used internally by Fortune 500 recruiting teams.

Do NOT design a marketing website.

Do NOT design multiple pages.

Do NOT create a collage.

Generate ONLY ONE dashboard screen.
